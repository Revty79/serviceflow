# Client-Zero Electrician Launch Checklist

Use this checklist to finalize the first electrician deployment before go-live.

## Business Details
- [ ] Business name confirmed
- [ ] Owner/admin email confirmed
- [ ] Phone number confirmed
- [ ] Service area confirmed
- [ ] Preferred customer contact method confirmed

## Branding
- [ ] Logo ready
- [ ] Brand primary color selected
- [ ] Brand secondary color selected
- [ ] Brand accent color selected

## Services and Operations
- [ ] Services offered confirmed
- [ ] Emergency availability policy confirmed
- [ ] Appointment windows confirmed
- [ ] Intake questions reviewed for customer clarity

## Website and Domain
- [ ] Domain name selected and configured
- [ ] Public page copy reviewed
- [ ] CTA text reviewed

## Launch Notes
- [ ] Admin account created and password changed from temporary seed password
- [ ] Launch notes documented (handoff contacts, timeline, and support plan)

## Post-Launch Testing Checklist
- [ ] Public `/request` form submits successfully
- [ ] New lead appears in `/admin/leads`
- [ ] Lead status update works
- [ ] Lead note creation works
- [ ] `/admin/settings` changes update public pages
- [ ] `/admin/services` changes update `/services` and `/packages`
- [ ] `/admin/intake` changes update `/request`
